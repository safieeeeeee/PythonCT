КТ 5 — Напоминалка

Запуск из папки работы:
python main.py

Нужен Python 3 с Tkinter. В обычном установщике Python для Windows этот компонент доступен как Tcl/Tk and IDLE.
Дополнительные библиотеки не нужны.

Задачи хранятся в tasks.txt, по одной в строке:
2026-10-20|Название задачи

Слева стоит дата в формате год-месяц-день, справа — текст. Пустые строки разрешены.
Можно добавлять и удалять строки обычным текстовым редактором.
После сохранения нажмите «Перечитать файл».

Красным показаны прошедшие задачи, жёлтым — сегодняшние, зелёным — будущие.
Примеры дат подготовлены на 13 октября 2026 года. Программа берёт текущую дату компьютера.
Для отправки работы сохраните main.py и tasks.txt рядом.
