КТ 2. Игра «Виселица на поле чудес», версия 3

Запуск: python main.py

Программа выбирает случайное слово. Вводи по одной букве.
Регистр не важен. Ё и Е считаются разными буквами.
Пустой ввод, несколько символов, цифры и повторные буквы
не засчитываются как ошибки. Все вхождения угаданной буквы открываются.
После семи неверных букв игра заканчивается.

Слова хранятся в words.txt: одно слово из букв на каждой строке.
Можно добавлять и удалять слова. Пустые строки и строки с цифрами,
пробелами внутри слова или знаками препинания пропускаются.
Сохраняй words.txt в UTF-8. В нём должно оставаться хотя бы одно слово.

Этапы рисунка находятся в stages/stage_1.txt — stage_7.txt.
После каждой новой неверной буквы программа читает соответствующий файл.
Сохраняй папку stages и оба файла Python вместе с words.txt.

В main.py находятся только импорт модуля и управление игрой через
его функции. Функции, глобальные переменные и вся работа с вводом,
выводом, словами и рисунками находятся в game.py.
