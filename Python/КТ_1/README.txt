КТ 1. Глухая бабушка

Запуск: python main.py

Вводи фразы и нажимай Enter. Бабушка слышит только фразы,
написанные заглавными буквами. Каждый раз она называет случайный
год от 1930 до 1950 включительно; случайный год может повториться.

Для завершения введи ПОКА! три раза подряд на отдельных строках.
Любая другая фраза сбрасывает счётчик прощаний.
Фраза ПОКА! ПОКА! ПОКА! в одной строке разговор не завершает.
