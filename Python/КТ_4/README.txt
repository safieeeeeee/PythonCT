КТ 4 — Пользователи и суперпользователи

Классы User и SuperUser находятся в users.py.
Запустите main.py, чтобы увидеть пример из задания.

Из папки этой работы:
python main.py

Для отправки работы сохраните оба файла рядом.
User.count считает обычных пользователей, SuperUser.count — суперпользователей.
Сравнение объектов использует скрытый рейтинг.
Чтение рейтинга и попытки его изменить дают сообщение из условия.
Пароль при чтении всегда скрыт восемью звёздочками.
